13. LVM – Logical Volume Management

LVM storage-কে flexibleভাবে পরিচালনা করতে সাহায্য করে। PV = Physical Volume, VG = Volume Group, LV = Logical Volume।

sudo pvcreate /dev/sdb
sudo pvs
sudo vgcreate vg_data /dev/sdb
sudo vgs
sudo lvcreate -L 10G -n lv_backup vg_data
sudo lvs

sudo mkfs.ext4 /dev/vg_data/lv_backup
sudo mkdir -p /backup
sudo mount /dev/vg_data/lv_backup /backup
df -h
এগুলো উদাহরণ command। /dev/sdb সত্যিই সঠিক, খালি এবং ব্যবহারের অনুমোদিত disk কিনা নিশ্চিত না হয়ে চালাবে না।

Scenario: Nginx website কাজ করছে না

# 1. Service status
sudo systemctl status nginx

# 2. Configuration test

# 3. Listening ports

# 5. Disk space

# 6. প্রয়োজন হলে restart

# 7. Local HTTP response verify
